# [Kiro-cli]  
Kiro cli는 터미널에서 실행되는 에이전트형 어시스턴트로 코딩에 특화되어 있지만, 커맨드 라인에서 할 수 있는 모든 작업을 도와줄 수 있다.
  - 문서 작성, 빌드 실행, 파일 검색, 주제 조사 등. 이 가이드에서는 핵심 아키텍처, 내장 기능, 효과적으로 사용하는 팁



## 세션 작업
kiro-cli 에서는 현재 claude-code 처럼 세션을 name으로 관리하는 방법이 없다. 세션 중에는 /session-id 커맨드를 통해 id 값을 확인할 수 있으며 해당 id로 세션을 재개할 수 있다.  
```bash
# kiro-cli 에서 /session-id 입력
/session-id
● Session ID: 08cb73e4-33d6-4d7c-afc3-d41b3ea43e60
  Resume with: kiro-cli --resume-id 08cb73e4-33d6-4d7c-afc3-d41b3ea43e60
```

```bash
# 이전 세션 목록 확인
kiro-cli chat --list-sessions

# 대화형 선택 피커 (제목, 시간, 메시지 수 표시)
kiro-cli chat --resume-picker

# 가장 최근 세션 바로 이어가기
kiro-cli chat --resume

# 특정 세션 ID로 이어가기
kiro-cli chat --resume-id <SESSION_ID>
```

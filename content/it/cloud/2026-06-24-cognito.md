# [Cognito](https://docs.aws.amazon.com/cognito/latest/developerguide/what-is-amazon-cognito.html)  

AWS Cognito는 웹 및 모바일 애플리케이션에 인증, 인가, 사용자 관리 기능을 제공하는 완전 관리형 서비스이다. Cognito User Pool은 OIDC(OpenID Connect) Provider 역할을 수행하여 표준 OAuth 2.0 / OIDC 프로토콜 기반의 인증 흐름을 지원한다. 클라이언트 애플리케이션은 Cognito가 발급하는 ID Token, Access Token, Refresh Token을 통해 사용자 인증 상태를 확인하고 API 접근을 제어할 수 있다. 외부 IdP(Google, SAML 등)와의 페더레이션도 지원하므로 기존 사내 인증 시스템과 연동하여 SSO를 구현할 수 있다.



## 1. Architecture (OIDC Provider)

```bash
┌─────────────────────────────────────────────────────────────────────────────────────┐
│                    OIDC Authorization Code Flow (GitLab 예시)                         │
└─────────────────────────────────────────────────────────────────────────────────────┘

  사용자 (브라우저)              GitLab (OIDC Client)              Cognito (OIDC Provider)
        │                              │                                │
        │ 1. gitlab.bys.digital 접속    │                                │
        ├─────────────────────────────>│                                │
        │                              │                                │
        │ 2. "Cognito 로그인" 버튼 클릭    │                                │
        ├─────────────────────────────>│                                │
        │                              │                                │
        │ 3. 302 Redirect  ()          │                                │
        │    Location: https://cognito.bys.digital/oauth2/authorize
        │    ?response_type=code                                        │
        │    &client_id=4ql19bt...                                      │
        │    &redirect_uri=https://gitlab.bys.digital/users/auth/openid_connect/callback?code=abc123
        │    &scope=openid+profile+email                                │
        │    &state=random_csrf_token                                   │
        │<─────────────────────────────│                                │
        │                              │                                │
        │ 4. Cognito 로그인 페이지 접속 (브라우저 자동 이동)                     │
        ├──────────────────────────────────────────────────────────────>│
        │                              │                                │
        │ 5. ID/PW 입력 및 인증 요청                                        │
        ├──────────────────────────────────────────────────────────────>│
        │                              │                                │
        │                              │       ┌────────────────────┐   │
        │                              │       │ Cognito 내부 처리:   │   │
        │                              │       │ • 사용자 인증 확인     │   │
        │                              │       │ • code 생성         │   │
        │                              │       │ • code 매핑 저장:    │   │
        │                              │       │   code: abc123     │   │
        │                              │       │   client_id: 4ql.. │   │
        │                              │       │   user: user@co..  │   │
        │                              │       │   redirect_uri:    │   │
        │                              │       │     gitlab.../cb   │   │
        │                              │       │   expires: 5min    │   │
        │                              │       │   used: false      │   │
        │                              │       └────────────────────┘   │
        │                              │                                │
        │ 6. 302 Redirect                                               │
        │    Location: gitlab.bys.digital/users/auth/openid_connect/callback
        │    ?code=abc123                                               │
        │    &state=random_csrf_token                                   │
        │<──────────────────────────────────────────────────────────────│
        │                              │                                │
        │ 7. callback URL 호출          │                                │
        │    GET /callback?code=abc123 │                                │
        │    (브라우저 자동 이동)          │                                │
        ├─────────────────────────────>│                                │
        │                              │                                │
        │                              │ 8. Token 교환 요청 [백채널]        │
        │                              │    POST /oauth2/token          │
        │                              │    • code=abc123               │
        │                              │    • client_id=4ql19bt...      │
        │                              │    • client_secret=idbkdq...   │
        │                              │    • redirect_uri=gitlab.../cb │
        │                              ├───────────────────────────────>│
        │                              │                                │
        │                              │       ┌────────────────────┐   │
        │                              │       │ Cognito 검증:       │   │
        │                              │       │ ✓ code 존재?        │   │
        │                              │       │ ✓ client_id 일치?   │   │
        │                              │       │ ✓ client_secret?   │   │
        │                              │       │ ✓ redirect_uri?    │   │
        │                              │       │ ✓ 미사용?           │   │
        │                              │       │ ✓ 만료 안 됨?        │   │
        │                              │       │ → 모두 통과: 발급     │   │
        │                              │       └────────────────────┘   │
        │                              │                                │
        │                              │ 9. Token 반환                   │
        │                              │    • id_token (JWT)            │
        │                              │    • access_token              │
        │                              │    • refresh_token             │
        │                              │<───────────────────────────────│
        │                              │                                │
        │                              │ 10. Token 검증 (내부)            │
        │                              │    • JWT 서명 검증 (JWKS)        │
        │                              │    • sub, email, groups 추출    │
        │                              │    • 사용자 세션 생성              │
        │                              │                                │
        │ 11. 로그인 완료 (세션 쿠키 발급)   │                                │
        │<─────────────────────────────│                                │
        │                              │                                │
```

## 2. Implementation

### 2.1 Cognito App Client 생성

- Allowed callback URLs
  - https://gitlab.bys.digital/users/auth/openid_connect/callback

- Allowed sign-out URLs
  - https://gitlab.bys.digital
  - https://gitlab.bys.digital/users/sign_in

### 2.2 Cognito Managed Login 스타일 연결

### 2.3 EKS Secret 생성 
`provider.json`
```json
{
  "name": "openid_connect",
  "label": "Cognito",
  "args": {
    "name": "openid_connect",
    "scope": ["openid", "profile", "email"],
    "response_type": "code",
    "issuer": "https://cognito-idp.ap-northeast-2.amazonaws.com/ap-northeast-2_abcdef",
    "discovery": true,
    "client_auth_method": "basic",
    "uid_field": "sub",
    "end_session_endpoint": "",
    "client_options": {
      "identifier": "abcdef",
      "secret": "abcdef",
      "redirect_uri": "https://gitlab.bys.digital/users/auth/openid_connect/callback"
    }
  }
}
```

```bash
kubectl --context eks-shared create secret generic gitlab-cognito-oidc -n gitlab --from-file=provider=provider.json

kubectl --context eks-shared rollout restart deployment -l app=webservice -n gitlab
```

### 2.4 GitLab Helm values.yaml
```yaml
global:
  ## https://docs.gitlab.com/charts/charts/globals#configure-appconfig-settings
  ## Rails based portions of this chart share many settings
  appConfig:
    omniauth:
      enabled: true
      autoSignInWithProvider: ""
      allowSingleSignOn:
        - openid_connect
      blockAutoCreatedUsers: false
      providers:
        - secret: gitlab-cognito-oidc  ## When domain(bys.digital) change, secret also have to be changed. 

## Cert-manager (Conflicts with ArgoCD)
installCertmanager: false
certmanager:
  installCRDs: false
```

### 2.5 Cognito SignOut 설정 (콘솔에서 수동)
Admin Area > Settings > General > Sign-in restrictions > Sign-out page URL:
  - https://cognito.bys.digital/logout?client_id=4ql19btig67h6sjc4e0k6ps4ck&logout_uri=https%3A%2F%2Fgitlab.bys.digital%2Fusers%2Fsign_in

ArgoCD 같은 경우에는 logoutURL을 통해서 처리하며 마찬가지로 logout_uri의 주소는 Cognito의 `Allowed sign-out URLs` 설정에 들어있어야 거부(400 Bad Requests)되지 않고 정상 처리가 된다.  
```
oidc.config: |
  name: Cognito
  issuer: https://cognito-idp.ap-northeast-2.amazonaws.com/ap-northeast-2_ZYGxHkpW8
  clientID: 22tgr8bnfsg9a3sgu4k90de80o
  clientSecret: $oidc.cognito.clientSecret
  requestedScopes:
    - openid
    - profile
    - email
  requestedIDTokenClaims:
    cognito:groups:
      essential: true
  logoutURL: https://cognito.bys.digital/logout?client_id=22tgr8bnfsg9a3sgu4k90de80o&logout_uri=https%3A%2F%2Fargocd.bys.digital
```
